# 📚 Bookstore Project

A **full-stack Bookstore application** built with **Java Spring Boot** (backend) and **HTML/CSS/JavaScript** (frontend).  
Allows users to manage books, perform CRUD operations, and view a responsive interface.

## Features

- Add, update, delete, and view books
- User authentication (login/register)
- Cart and checkout functionality
- REST APIs for backend operations
- Responsive frontend interface
